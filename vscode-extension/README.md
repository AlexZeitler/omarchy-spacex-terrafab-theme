# SpaceX Terrafab Theme

A dark color theme based on the SpaceX Terrafab: near-black violet as background, light blue-grey as foreground, with cool accents in ice blue, cyan and lilac.

The theme is part of the [Omarchy SpaceX Terrafab theme](https://github.com/AlexZeitler/omarchy-spacex-terrafab-theme), which covers Hyprland, Waybar, terminals, btop and more. Installing the Omarchy theme selects this VSCode theme automatically.

## Installation

Search for `SpaceX Terrafab Theme` in the Extensions view, then pick `SpaceX Terrafab` under `Preferences: Color Theme`.
